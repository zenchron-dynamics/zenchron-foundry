## Grounding Block

**Goal:** Strict, factual self-audit before adding features. Zero tolerance for fake completeness. Implement only P0.

**Method:** Real inspection — rebuilt and *ran* representative images (not just `--version`), validated FPM config (`php-fpm -t`), ran `docker compose config` on examples, resolved base digests, functionally tested `.dockerignore`, checked the live CI run. Findings are evidence-backed.

**Honesty corrections surfaced during audit:**

- The literal build commands in the task (`docker build -f images/php-fpm/8.3/Dockerfile .`) **fail as written** — context `.` (repo root) breaks the relative `COPY php.ini`. Correct form: `docker build images/php-fpm/8.3`.
- Legacy FPM had only ever been run in CLI mode in prior sessions; actual `php-fpm` was started here and confirmed **not** broken (pools merge, runs as uid 10001).
- "CVE policy stricter for legacy" is challenged — stricter gating on unfixable EOL CVEs is the wrong control; isolation + visibility is correct.

**Scope of changes this pass:** 3 P0 fixes only (digest pinning, `.dockerignore`, Makefile label slug). No P1/P2/P3 touched.

## Distroless Feasibility Review

| Family | True distroless? | Recommended base | Runtime limits | Debug limits | Security tradeoff |
|---|---|---|---|---|---|
| php-fpm | No | Chainguard Wolfi (current) | needs many shared libs; busybox kept for healthcheck | `php` present, no curl/cgi-fcgi | near-distroless; tiny shell surface accepted |
| php-cli | No | Wolfi | shared-lib needs | busybox sh | same |
| php-worker | No | Wolfi + `tini` | needs init for signals | busybox sh | same; tini justified |
| php-frankenphp | No | upstream `dunglas/frankenphp:*-alpine` | full Alpine userland | apk present | weakest of set; pin digest (done) |
| caddy | Partial | `caddy:2-alpine` non-root | static Go binary | shell present | minimal; could harden later |
| nginx | No | `nginx-unprivileged:alpine` | needs libs + temp dirs | shell present | minimal, purpose-built |

**Verdict:** true Google-distroless is not appropriate for PHP and the repo correctly does not fake it. Wolfi hardened-minimal is the right, honest choice; `docs/distroless-strategy.md` documents it accurately.

## Prioritized Remediation Plan

### P0 — blocks secure usage (all implemented this pass)

1. **Pin all base images by digest** — Reason: mutable `latest`/floating tags violate the "no mutable latest" non-negotiable and supply-chain integrity. Files: all 19 Dockerfiles. Acceptance: every `ARG *_BASE` contains `@sha256:`. Validation: `grep -L '@sha256:' images/*/Dockerfile images/*/*/Dockerfile` finds no base ARG; CI build green. ✅
2. **`.dockerignore` for example build contexts** — Reason: `COPY . .` leaks `.env`/`.git`/credentials → violates "no secrets in images". Files: `examples/{laravel,symfony,frankenphp}/.dockerignore`. Acceptance: `.env`/`.git`/`vendor` excluded. Validation: busybox copy test. ✅
3. **Makefile OCI source-label slug** — Reason: `make`-built images carried wrong `image.source`. Files: `Makefile`. Acceptance: label → `…/zenchron-foundry`. Validation: `grep image.source Makefile`. ✅

### P1 — before first internal production use

1. **Disable PHP JIT by default** — Files: `images/php-fpm/*/php.ini`, frankenphp `php.ini`. Accept: `opcache.jit=disable`. Validate: `php -i | grep 'opcache.jit '`.
2. **Worker liveness healthcheck** — Files: worker Dockerfiles + docs. Accept: HEALTHCHECK or documented probe + heartbeat. Validate: `docker inspect --format '{{.Config.Healthcheck}}'`.
3. **Enforce branch protection on `master`** — Files: GitHub settings. Accept: PR + status checks required, no force-push. Validate: `gh api repos/…/branches/master/protection`.
4. **Create real CODEOWNERS teams** — Files: org teams + `CODEOWNERS`. Accept: review routing resolves. Validate: PR shows owner request.
5. **Signed commits** — Files: contributor `git config commit.gpgsign true` + key. Accept: `git log --show-signature` good sig.
6. **Grant consumer pull access / package linking** — Files: GHCR package settings. Accept: read-only token pulls. Validate: `docker pull` with `read:packages` token.

### P2 — before broad reuse

1. Real serving-readiness healthchecks for caddy/frankenphp (`/healthz`).
2. Legacy migration-deadline tracker (issue template + dated owners).
3. Multi-arch `linux/arm64` builds (matrix already structured).
4. `make doctor` target checking local tool availability with install hints.
5. Guard `make build` against `build-frankenphp PHP=7.4/8.0`.

### P3 — polish

1. Reconcile prose project-name vs repo (`docker-platform` ↔ `zenchron-foundry`).
2. Static-binary FPM healthcheck to drop busybox (true shell-less).
3. Kyverno/Sigstore admission-policy doc for future K8s.
