# Release withdrawal records

One record per withdrawn release. The required fields and the procedure are in
[`policies/support-policy.yaml`](../../../policies/support-policy.yaml)
(`withdrawal:`) and [`docs/release-withdrawal.md`](../../release-withdrawal.md).

**A withdrawal record is not a deletion.** Published digests are immutable and
stay pullable; withdrawal means publishing that a digest must not be used. The
consumers most affected are precisely the ones following this platform's advice
to pin by digest, so the advisory is the mechanism — there is no technical
recall.

Records generated by `scripts/exercise-withdrawal.sh --simulate` are written
here with `simulated: true` and are ignored by tooling that counts real events.
